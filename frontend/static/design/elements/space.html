The base font size of SciStarter is 18px. As such the default line-height is 28.8px (1.6x base). This number is used to create a vertical rhythm. Tailwind CSS needs a multiplier, which is set at 3.6x because 3.6 x 8 = 28.8.

SciStarter uses Tailwind 4 and has customized the spacing variable to adhere to this vertical rhythm. Tailwind works with utility classes for space such as p-, m-, gap-, etc. where you put a multiplier within those classes.

Note that typography has default spacing built in. This is mostly for "reading" text. It will be overridden for components such as cards. Otherwise you should not have to add space to text tags.

The following are notes on space classes and how they should be used:

Multiplier Ultimate Pixel Size Notes
0 0 Remove spacing
4 14.4px The default half space. Used for space after text in related contexts (same section of text).
8 28.8px The default space. Used for padding in a container, and gaps in flexboxes.
16 57.6px The default double space. Used to separate sections of a page.
Numbers lower than 8. Variable Generally used to tighten up design and try to adhere to a vertical rhythm. To be used sparingly.
Numbers higher than 8. Variable Generally used to loosen up design and try to adhere to a vertical rhythm. To be used sparingly.
