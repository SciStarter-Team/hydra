Template Syntax Guide

Parameters

Declare parameters at the start of your template. These appear in the slot properties panel.

{$ param title label="Page Title" default="Welcome" description="Main heading" $}
{$ param count default=5 $}
{$ param show_border $}
  • label - Display name (auto-generated from param name if omitted)
  • default - Default value: "string" or 42
  • description - Help text shown below the input

Output Values

{$= title $}      <%# HTML-escaped output %>
{$- html_content $}  <%# Raw output (no escaping) %>

Conditionals

{$ if show_border $}
  <div class="border">...</div>
{$ else if alt_style $}
  <div class="alt">...</div>
{$ else $}
  <div>...</div>
{$ /if $}

Loops

{$ each item in items $}
  <li>{$= item $}</li>
{$ /each $}

{$ times 3 $}
  <div>Repeated content</div>
{$ /times $}

Use {$= iteration $} inside loops to get a unique identifier.

Slots

Define areas where other components can be placed.

{$ slot header $}
  <!-- Default content if empty -->
{$ /slot $}

{$ slot sidebar $}{$ /slot $}

Literal Output

Use ^ to output template syntax literally. Use *var to interpolate variables.

{$^ if foo $}        <%# Outputs: {$ if foo $} %>
{$^ slot *name $}    <%# Outputs: {$ slot value_of_name $} %>

<%# Dynamic slots in a loop: %>
{$ times 3 $}
  {$^ slot *iteration $}{$^ /slot $}
{$ /times $}

The number of * must match the number of ^ for interpolation.

Translation

Wrap wording in tr and it appears under Translations to be translated. Until someone translates it, readers see it exactly as written here. The phrase must be quoted, and it goes out as markup, so a link inside it can stay part of the sentence.

{$! tr "Find a project that needs your help." $}

<%# Single quotes, so the markup inside keeps its own: %>
{$! tr 'Read <a href="/about">about us</a>.' $}

<%# Same words, different meaning somewhere else: %>
{$! tr "Open" context="verb" $}

Note the !, which means “run this when the page is viewed.” Placing a component renders it, so without the ! the phrase would be translated once and frozen into whichever language you were reading. Unlike ^, it does not need counting: it means the same thing however deeply this component is placed inside others. Saving a component that leaves it out is refused. {$! widget ... $} works the same way, and for the same reason.

Run At View Time

Some directives have to run for each reader rather than once, when the component is placed. Mark those with !.

{$! tr "Translated for whoever is reading." $}
{$! widget webinar_list groups="upcoming" $}

This is not the same as ^. ^ is a choice about when to run something that could legitimately run at either time, and it counts down by one for each placement. ! is for things with only one right answer, so it never counts down and never needs adjusting for how a component is used. It applies to a directive that stands on its own, not to a block like if or each.
