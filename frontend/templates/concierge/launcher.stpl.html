<%# Flower's floating presentation: an "Ask Flower" button at the corner of the page, and the panel it opens (a bottom sheet on narrow screens). Opening and closing are the browser's own Popover API, so they need no script. The panel is a manual popover so that clicking the page behind it does not close it; Escape does, while focus is inside. The chat is fetched into the panel the first time it opens on a page. "Hide Flower" lasts for the rest of the visit (sessionStorage), so the launcher stays out of the way of someone who has dismissed it as they move from page to page. That is a per-tab display preference with nothing for the server to know, so it lives in the browser. htmx 4 fires htmx:after:swap on the element that made the request, not on the swap target, so the handler that settles the freshly loaded chat (scrolled to its latest message, input focused where there is a keyboard) sits on the launcher button. The inline script runs as soon as the element is parsed, before first paint, so a hidden launcher never flashes into view. %>
